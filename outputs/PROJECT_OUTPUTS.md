## Current authoritative framing

The current README and Portfolio detail page are the authoritative description of the ongoing study:

**passive smartphone sensing → PHQ-9 severity prediction → individualized behavioral anomaly detection → lagged temporal analysis of subsequent PHQ-9 change**.

BRIGHTEN V1 is the primary analysis cohort, while BRIGHTEN V2 is reserved for reproducibility / robustness checking when appropriate. No final predictive-performance claim is reported yet because the study is ongoing.

## Scope and provenance note

The seminar deck represents an earlier methodological checkpoint. Where terminology or emphasis differs, the current README takes precedence. In particular, the present study emphasizes passive-sensing-only PHQ-9 prediction, individualized within-person deviation, and temporal ordering between detected anomalies and later PHQ-9 change.

## Data-use note

Participant-level BRIGHTEN data are not redistributed because access is governed by the original data-use conditions. Analysis code will only be released when compatible with those restrictions and after the analysis interface is stabilized.
